# 02 · 贪心算法路线规划与时间调度

- **日期**：2026-10-27
- **对应模块**：`src/js/modules/planner.js`
- **目标**：为选定地市自动生成一条「不走回头路」的非遗半日游路线与时间轴

---

## Prompt 原文（第一轮）

```
请帮我用原生 JavaScript（ES6，不引入任何第三方库）写一个函数，
解决"非遗半日游路线规划"问题：

【输入】
- pool：候选景点数组，每个元素形如 { name, lng, lat }
- anchor：[经度, 纬度]，表示出发点
- 约束：最多选 4 个点

【要求】
1. 用贪心算法（每次选离当前位置最近的未访问点）排出访问顺序
2. 根据排序结果生成时间轴：从早上 9:00 出发，每个点游玩 90 分钟
3. 输出形如 "第 1 站：XXX，09:00 - 10:30"

【代码要求】
- 必须有清晰的注释
- 注意数组越界与空集合的边界情况
```

---

## AI 产出摘要

给出了贪心最近邻的核心逻辑（`while` 循环 + 内层 `for` 求最小距离），时间复杂度 O(n²)，并给出了基础时间轴渲染。

## 选手评审与干预（关键！）

| 问题 | 现象 | 修复方案 |
| --- | --- | --- |
| **未计入车程** | AI 排出的时间轴把 4 个点排成 9:00-16:30 连续无缝，现实中不可能 | 引入 `TRAVEL_MINUTES = 30` 交通缓冲，每次 `cursor = leave + 30` |
| **时间戳进位错误** | 出现 `09:90` 这类非法时间 | 抽出 `fmt(minutes)`，用 `Math.floor(m/60)` 与 `m%60` 正确进位 |
| **无上限保护** | 若某地市数据 > 10 条，路线会过长且时间轴溢出 | 增加 `MAX_STOPS = 4`，用 `slice()` 截断 |
| **空集合崩溃** | 传入数据为空的地区时抛异常 | 增加 `if (!pool.length) return null` |
| **导航信息缺失** | 只输出时间，用户不知道总里程 | 增加分段欧氏距离累加，按纬度换算为公里数 |

## 演进过程

```javascript
// ❌ AI 初版（省略车程）
startMins += 90;

// ✅ 最终版本（游玩 90 分钟 + 车程 30 分钟）
cursor = leave + opt.TRAVEL_MINUTES;
```

## 最终落地

`planner.js` 采用**纯函数**设计：`plan(city, options) -> { route, timeline, startTime, endTime, approxKm }`，
与 UI 完全解耦，可独立单元测试；所有超参（出发时间 / 游玩时长 / 车程 / 上限 / 锚点）统一收纳于 `config.js` 的 `PLANNER` 节点，便于调优。
