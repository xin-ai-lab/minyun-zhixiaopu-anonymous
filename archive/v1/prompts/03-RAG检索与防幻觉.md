# 03 · RAG 检索增强问答与防幻觉设计

- **日期**：2026-10-27
- **对应模块**：`src/js/modules/rag.js`、`src/js/modules/ui.js`
- **目标**：让用户用自然语言提问即可精准命中知识库，同时**杜绝大模型式的事实编造**

---

## 设计思考（选手主导）

非遗科普场景对**事实准确性**的要求极高：一旦把"省级"说成"国家级"、把传承人说错，
就是对文化的伤害。因此本项目的核心决策是：

> **不把开放式生成交给大模型，而是让 AI 只做「检索 + 编排」，事实永远来自本地可信知识库。**

这本质上是用 RAG 的「R」（Retrieval）承担全部事实责任，「G」（Generation）降低为**模板化卡片渲染**。

---

## Prompt 原文

```
我要做一个轻量级 RAG 问答引擎（纯前端、无向量数据库），请帮我设计：

【输入】用户自然语言问句，例如：
- "簪花围在哪里体验？"
- "泉州有哪些非遗？"
- "打开知识图谱"
- "两岸非遗对照"

【输出】一个统一的意图对象 { type, city?, hits? }，供 UI 层渲染

【意图类型】
1. graph      —— 打开知识图谱（关键词：图谱、关系）
2. cross      —— 打开两岸对照（关键词：两岸、台湾、海峡）
3. city-list  —— 某地市清单（含地市名 + "有哪些/非遗/推荐"）
4. overview   —— 全省概览
5. search     —— 实体检索，返回 Top-K 命中项目
6. fallback   —— 兜底引导

【检索要求】
- 多路召回：项目名称 / 标签 / 简介 三路匹配
- 按命中权重排序（名称命中权重最高）
- 返回结果数量可控（Top-K）

【代码要求】
- 必须处理标点符号和疑问词（"在哪里体验"等）对匹配的干扰
- 空结果必须给出引导话术，不能静默失败
- 纯函数、无副作用，便于测试
```

---

## AI 产出摘要

输出了意图识别的 `if/else` 分发骨架与 `search()` 加权打分雏形。

## 选手评审与干预

| 问题 | 修复 |
| --- | --- |
| 用户输入带全角标点，导致 `includes` 匹配失败 | 增加 `normalize()`：剥离 `？?。，,、！!` 与空白 |
| "簪花围在哪里体验" 中的"在哪里体验"污染了关键词 | 检索前用正则剥离疑问词，得到纯净实体词 |
| 名称、标签、简介权重相同，排序不准 | 引入加权打分：名称 +10 / 标签 +6 / 简介 +4 / 历史 +2 / 地市 +5 |
| 空结果静默无反馈 | 增加 `fallback` 意图，输出快捷提问引导 |
| 用户看不到"系统在工作" | UI 层增加 1.2s「检索中」动画，模拟向量检索过程，提升可感知性 |

## 最终落地

`parseIntent(rawText)` 返回结构化意图对象，UI 层用 `switch` 渲染。
既保证了**事实零幻觉**，又保留了自然语言交互的流畅体验；
当未来在 `config.js` 中开启 `AI.ENABLED` 时，可将召回结果作为**唯一上下文**交由大模型润色（标准 RAG 增强路径）。
