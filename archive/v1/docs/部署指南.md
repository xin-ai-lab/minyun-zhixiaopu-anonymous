# 部署与运行指南

> 本项目为**纯前端静态应用**，零后端、零构建，可部署到任意静态托管平台。

---

## 一、环境要求

| 项目 | 要求 |
| --- | --- |
| 浏览器 | Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+（需支持 ES6+） |
| 网络 | 首次加载需要访问地图瓦片服务；其余功能均可离线运行 |
| Node.js | **非必需**，仅在需要本地服务器或环境变量注入时需要（≥ 18） |

---

## 二、本地运行（三种方式）

### 方式一：直接打开（最简）

```
双击 index.html
```

Leaflet 已本地化至 `src/vendor/leaflet/`，`file://` 协议下即可完整运行。

### 方式二：npm 脚本

```bash
npm start          # 启动 http-server 并自动打开浏览器，默认端口 8080
```

### 方式三：Python 内置服务器

```bash
python -m http.server 8080
# 访问 http://127.0.0.1:8080
```

## 三、环境变量配置

### 3.1 生成配置文件

```bash
cp .env.example .env      # Windows 可用 copy .env.example .env
npm run env               # 生成 src/js/env.generated.js
```

### 3.2 变量说明

| 变量 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `APP_NAME` | 否 | 闽韵智小铺 | 应用名称 |
| `APP_SUBTITLE` | 否 | 福建非遗智能科普助手 | 副标题 |
| `MAP_TILE_URL` | 否 | 高德路网瓦片 | 地图瓦片地址 |
| `WIKI_API_BASE` | 否 | 维基共享资源 API | 开放图库检索接口 |
| `AI_API_BASE` | 否 | 空 | 可选的在线大模型接口 |
| `AI_API_KEY` | 否 | 空 | **敏感信息，禁止入库** |
| `AI_MODEL` | 否 | deepseek-chat | 大模型名称 |

> ⚠️ **安全提示**：`.env` 与 `src/js/env.generated.js` 已在 `.gitignore` 中排除。
> 请勿将任何 API 密钥硬编码进源码或提交到公开仓库。

### 3.3 未配置时的行为

若不创建 `.env`，应用会使用 `config.js` 中的**公开安全默认值**正常启动，
所有功能均可用（地图与图库走公开免费接口）。

## 四、部署到静态托管

### 4.1 GitHub Pages

```bash
git remote add origin https://github.com/<用户名>/minyun-ich-assistant.git
git push -u origin main
```

进入仓库 `Settings → Pages`，Source 选择 `Deploy from a branch`，分支选 `main / (root)`，
保存后访问 `https://<用户名>.github.io/minyun-ich-assistant/`。

> `.nojekyll` 空文件建议一并提交，避免 Jekyll 忽略 `src/` 下划线开头文件。

### 4.2 Gitee Pages

在 Gitee 仓库页面点击 `服务 → Gitee Pages`，选择 `master/main` 分支与根目录，点击「启动」。

### 4.3 Vercel / Netlify

- 导入 Git 仓库后，**Framework Preset 选 `Other`**；
- Build Command 留空；
- Output Directory 填 `.`（根目录）；
- 直接部署即可，无需任何构建步骤。

### 4.4 对象存储 / CDN

将整个项目目录（除 `.git`、`node_modules`）上传至 OSS / COS / S3 等对象存储，
开启静态网站托管即可。由于全部资源使用**相对路径**引用，无需修改任何配置。

## 五、常见问题（FAQ）

**Q1：地图是空白 / 灰块？**
地图瓦片来自公网服务，请检查网络。若内网环境，可在 `.env` 中把 `MAP_TILE_URL`
换为自建瓦片服务地址。**即使瓦片加载失败，标记点与全部问答功能依然可用。**

**Q2：非遗照片显示"未找到公开授权照片"？**
正常情况不会出现 —— 48 项非遗均已内置实景照片（`assets/sites/`）。只有当某项目
既无内置图、也无用户上传图时，才会退到在线开放图库；在线图库同样找不到才会提示手动上传。

**Q3：上传照片后刷新丢失？**
请检查浏览器是否处于隐私模式（IndexedDB 与 LocalStorage 被禁用）。
用户上传的照片写入 **IndexedDB**（配额按磁盘容量计算），正常情况下可一次上传数十张；
若 IndexedDB 不可用，应用会自动降级到 LocalStorage（5MB 单源上限），此时大批量上传可能失败。

**Q4：端口被占用？**
`npm start -- -p 8081` 或 `python -m http.server 8081`。

**Q5：能否离线运行？**
可以。除地图瓦片与在线图库检索外，所有功能（问答、图谱、路线规划、详情、两岸对照）
均不依赖网络。可将瓦片服务替换为内网地址实现完全离线。
