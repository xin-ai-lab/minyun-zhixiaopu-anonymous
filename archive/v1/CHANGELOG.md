## [1.1.0] - 2026-10-31

### 新增 Added

- **内置非遗实景图库**：随包分发 **48 张真实非遗实景照片**（`assets/sites/<项目id>.jpg`，等比压缩至最长边 800px / JPEG 0.8，全库约 3.1MB），地图标记、问答卡片、地图气泡与详情页默认展示实景照片，离线与弱网环境同样可用；新增 `src/js/data/gallery.js` 图库索引
- **知识库扩充**：补充「漳州八宝印泥」（传承人 杨锡伟）与「莆田木雕」（传承人 郑春辉）两项国家级非遗，知识库由 46 项增至 **48 项**

### 修复 Fixed

- **批量上传存储失败**：原方案把压缩后的 Base64 全部写入 LocalStorage，受浏览器 5MB 单源配额限制，批量导入 40+ 张照片时必然触发 `QuotaExceededError`（提示「图片过大，存储失败。建议单张图片小于 1MB」，实际与单张大小无关）。改为 **IndexedDB** 持久化用户上传照片（配额按磁盘容量计），保留 LocalStorage 数据一次性迁移与降级回退，批量上传 48 张不再失败
- 批量上传完成后同步刷新问答卡片与详情弹窗图片，不再只刷新地图标记

### 变更 Changed

- 统一取图优先级：**用户上传 > 内置图库 > 在线图库**；内置图库已覆盖全部 48 项，正常情况不再发起在线图库请求，页面首屏更快、更稳定
- 用户自己上传的照片在问答卡片上显示「我的照片」金色角标、在地图标记上显示金色描边，与内置实景图库区分开
- `scripts/generate-env.js` 在缺少 `.env` 时回退读取 `.env.example` 的公开安全默认值并照常生成 `src/js/env.generated.js`，消除页面加载时 `env.generated.js` 的 404 控制台报错（行为与内置默认值完全一致）

## [1.0.0] - 2026-10-30

### 新增 Added

- **RAG 智能问答引擎**：意图识别（图谱 / 两岸 / 地市清单 / 全省概览 / 实体检索）+ 三路加权召回（名称 / 标签 / 简介）
- **福建非遗知识库**：收录 46 项代表性非遗，覆盖 10 个地市、7 大类别，含经纬度、级别、传承人、历史渊源、传承案例与游玩攻略
- **智能路线规划**：基于贪心最近邻算法生成最短游览顺序与时间轴（9:00 起，游玩 90 分钟 / 交通 30 分钟缓冲）
- **知识图谱可视化**：纯原生 SVG 环形放射布局，支持「全局视图」与「单项目关系网」两种模式
- **闽台两岸同源对照**：6 组同源非遗并列对照，含「同源共脉」结论
- **地图可视化**：Leaflet + 高德路网，46 个自定义标记，支持地市 + 类别双重筛选、4 条预设主题路线
- **照片上传与持久化**：单张 / 批量上传，Canvas 等比压缩后写入 LocalStorage
- **开放图库检索**：维基共享资源 CC 授权图片自动检索与缓存
- **环境变量注入机制**：`.env` → `scripts/generate-env.js` → `env.generated.js`

### 优化 Changed

- **Leaflet 本地化**：由 CDN 引用改为本地 `src/vendor/leaflet/`，摆脱运行时外链依赖，支持离线运行
- **代码结构重构**：由单文件 HTML 拆分为 `src/css`（4 个）+ `src/js`（13 个）模块，单一职责、便于维护
- **性能**：在线图库图片采用「逐张限流拉取（150ms 间隔）」，避免接口限流与首屏阻塞

### 修复 Fixed

- 修复直接 Base64 存储大图导致的 LocalStorage 配额溢出与页面卡死
- 修复路线规划未计入车程导致的时间轴偏差
- 修复时间戳进位格式化问题（如 9:90 → 10:30）
- 修复无图状态下标记不可见的问题（新增 Emoji 降级态）
- 修复 RAG 检索对标点、疑问词敏感导致漏召回的问题

### 安全 Security

- API 密钥等敏感信息一律通过环境变量注入，`.env` 与 `src/js/env.generated.js` 已加入 `.gitignore`
- 移除全部内联 `onclick`，改为事件委托，降低 XSS 攻击面
