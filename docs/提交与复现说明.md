## 已有线上仓库怎么更新

1. 用 Git 客户端打开本包 `01_源代码` 文件夹，它已经包含 `.git`。
2. 查看现有提交记录，确认原历史与本轮新提交都存在。
3. 添加真实远程 URL：`git remote add origin <实际仓库网址>`。若已存在 origin，用 `git remote -v` 检查，不随意覆盖。
4. 查看当前分支：`git branch --show-current`，将当前分支推送到现有远程对应分支。若远程已有新的不同提交，先取回并正常合并，禁止为图省事强推覆盖历史。
5. 在线上仓库 README 中补上提交文件链接，开启 Public 或给评委指定账号访问权限。
6. 使用未登录窗口或评委账号确认 README、代码、Git 历史和 Prompt 文件可打开。

没有 Git 命令行时，可使用 GitHub Desktop 或其他 Git 客户端添加已有本地仓库。网页拖拽上传普通文件不会保留本地提交历史，不能作为这项要求的替代。
