# 提交与复现说明

以用户确认的比赛截图为依据：GitHub/Gitee 仓库与细粒度历史；至少 3 个核心功能的完整 Prompt 迭代记录；10 分钟复现 README；5-8 分钟、1080p MP4，其中至少 2 分钟 AI 协作过程；不超过 30 页技术 PDF。

最终提交文件夹提供源码与便携运行压缩包、技术 PDF、演示 MP4、AI 协作记录压缩包，以及一份提交指引。源码包含原 12 次开发提交及后续改进的完整匿名历史；记录包含真实协作消息、工具调用和三条模块链索引。历史 Prompt 文档保留开发内容并隐去身份信息，明确只是原作者提供的摘要，不能替代旧聊天导出。本轮记录对应一个授权任务下的连续开发，模块链中的排错由 AI 执行，不虚构参赛者逐轮输入。

## 匿名材料与仓库地址

源码仓库地址在报名系统指定字段单独填写，不嵌入匿名评审文档。
本地源码和源码 ZIP 包含隐私处理后的 Git 历史；保留开发顺序与时间，
作者字段和历史文件中的身份信息均已移除，因此提交哈希与原版本不同。

完整解压 `01_作品源码与运行.zip` 后，进入“闽韵智小铺”，双击 `启动作品.cmd`。其余材料按照桌面文件夹内的“提交指引.txt”上传。
摄影图片沿用原作品，参赛者已确认授权；匿名评审材料不包含个人证件或联系方式。
