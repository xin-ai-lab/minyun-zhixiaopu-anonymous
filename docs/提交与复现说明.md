# 提交与复现说明

以用户确认的比赛截图为依据：GitHub/Gitee 仓库与细粒度历史；至少 3 个核心功能的完整 Prompt 迭代记录；10 分钟复现 README；5-8 分钟、1080p MP4，其中至少 2 分钟 AI 协作过程；不超过 30 页技术 PDF。

本地交付包含完整可运行源码、保留原 12 次提交的 Git 仓库、本轮真实协作消息和工具调用、三个模块链索引、技术 PDF、视频、字幕和操作手册。历史 Prompt 文档保留开发内容并隐去身份信息，明确只是原作者提供的摘要，不能替代旧聊天导出。本轮记录对应一个授权任务下的连续开发，模块链中的排错由 AI 执行，不虚构参赛者逐轮输入。

## 匿名材料与仓库地址

源码仓库地址在报名系统指定字段单独填写，不嵌入匿名评审文档。
本地源码和源码 ZIP 包含隐私处理后的 Git 历史；保留开发顺序与时间，
作者字段和历史文件中的身份信息均已移除，因此提交哈希与原版本不同。

现场演示请使用根目录的 `启动作品.cmd`。技术文档、视频和协作记录按“提交清单.md”选取。
正式提交前仍需补齐照片来源凭据；匿名评审材料不要附个人证件或联系方式。
