## 一、项目介绍

### 1.1 一句话简介

**闽韵智小铺**是一款面向大众的**福建非物质文化遗产智能科普助手**。用户只需用自然语言提问（例如「簪花围在哪里体验？」），即可获得结构化的非遗知识卡片、地图定位与游玩攻略；应用还能基于**贪心算法**为用户一键规划非遗主题半日游路线。

### 1.2 创作背景

福建是中国非物质文化遗产大省，拥有**妈祖信俗、泉州南音、送王船、安溪铁观音、武夷岩茶**等多项联合国人类非物质文化遗产。但目前大众了解非遗面临三重痛点：

| 痛点 | 具体表现 |
| --- | --- |
| **知识碎片化** | 非遗信息散落在新闻、百科、短视频中，缺乏结构化、可信的知识入口 |
| **决策成本高** | 想实地体验却不知道"去哪体验、多少钱、怎么安排半天时间" |
| **文化联结弱** | 闽台非遗同根同源，但缺少直观的对照呈现，难以感知文化血脉 |
| **内容幻觉风险** | 通用大模型容易对非遗信息张冠李戴、编造传承人与级别 |

### 1.3 解决方案

本项目以 **RAG（检索增强生成）** 思想为核心，构建了「**结构化知识库 → 意图识别 → 精准召回 → 卡片化生成**」的闭环：

- **46 项**精选福建非遗的**结构化知识库**（名称 / 级别 / 经纬度 / 传承人 / 历史渊源 / 传承案例 / 游玩攻略）；
- **10 个地市 + 7 大类别**的多维筛选与**地图可视化**；
- **贪心最近邻算法**驱动的智能路线规划与时间轴排程；
- **纯原生 SVG** 绘制的知识图谱与**闽台两岸同源对照**；
- **防幻觉设计**：只从本地可信知识库检索事实，不做开放式编造。

## 二、核心功能

| # | 功能 | 说明 |
| --- | --- | --- |
| 1 | **RAG 智能问答** | 自然语言提问 → 意图识别 → 三路关键词召回 → 非遗卡片作答，附「检索中」过程可视化 |
| 2 | **非遗知识图谱** | 纯原生 SVG 环形放射布局，展示「类别 → 项目 → 传承人 / 地域 / 同类」关系网络 |
| 3 | **智能路线规划** | 贪心最近邻算法计算最短游览顺序，自动生成从 9:00 起的**时间轴**与总里程 |
| 4 | **地图可视化** | Leaflet + 高德路网，46 个自定义标记，支持**地市 + 类别**双重实时筛选 |
| 5 | **闽台两岸对照** | 6 组同源非遗（歌仔戏 / 南音 / 博饼 / 妈祖 / 布袋戏 / 漆线雕）左右并列对照 |
| 6 | **照片上传与持久化** | 支持单张 / 批量上传，Canvas 等比压缩后写入 LocalStorage，刷新不丢失 |
| 7 | **开放图库检索** | 无图时自动从维基共享资源（CC 授权）检索实景图，规避版权风险 |

## 三、技术架构

### 3.1 技术选型

| 层次 | 技术 | 选型理由 |
| --- | --- | --- |
| 结构 | HTML5 语义化标签 | 无障碍友好，无需构建工具 |
| 样式 | CSS3 + Flexbox + CSS 变量 | 设计令牌统一管理色板，便于换肤与响应式适配 |
| 交互 | JavaScript ES6（IIFE 模块化） | 无需打包器，`file://` 双击即可运行，降低评审复现成本 |
| 地图 | Leaflet 1.9.4（**已本地化**） | 仅 ~147KB，摆脱 CDN 运行时依赖，可离线运行 |
| 图谱 | **原生 SVG 手写渲染** | 节点规模小（≤30），自研约 40 行即可，避免引入 300KB+ 图库 |
| 算法 | 贪心最近邻 Greedy NN | O(n²)，n≤4 场景下毫秒级给出近最优解 |
| 存储 | LocalStorage + Canvas | 纯前端持久化，无需后端与数据库 |

### 3.3 数据流

```
用户提问
   │
   ▼

   │
   ▼
[rag.js] parseIntent()  意图识别
   ├─ 图谱/两岸 ──────────► [graph.js] / [cross.js] 弹窗
   ├─ 地市清单 ──────────► 批量渲染卡片
   └─ 实体检索 ──► search() 三路召回（名称+标签+简介，加权排序 Top-K）
                                    │
                                    ▼
                          [ui.js] 渲染非遗信息卡片
                                    │
                                    ▼
                          [map.js] 标记同步高亮定位
```

## 四、安装与运行

本项目**零构建、零后端**，提供三种运行方式：

### 方式一：直接双击（最快）

```bash
# 直接双击 index.html 即可在浏览器打开（Leaflet 已本地化，file:// 协议可用）
```

### 方式二：本地静态服务器（推荐）

```bash
git clone <仓库地址>
cd 闽韵智小铺

# 方式 A：使用 npm 脚本（自动打开浏览器）
npm start

# 方式 B：使用 Python 内置服务器
python -m http.server 8080
```

打开 <http://localhost:8080> 或 <http://127.0.0.1:8080> 即可访问。

### 方式三：部署到任意静态托管

支持 GitHub Pages / Gitee Pages / Vercel / Netlify / 对象存储等任意静态托管，**无需 Node 环境**，上传即用。详见 [`docs/部署指南.md`](docs/部署指南.md)。

## 五、环境配置

### 5.1 变量清单

复制模板并按需修改：

```bash
cp .env.example .env
npm run env            # 将 .env 注入 src/js/env.generated.js
```

| 变量名 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `APP_NAME` | 否 | `闽韵智小铺` | 应用展示名称 |
| `APP_SUBTITLE` | 否 | `福建非遗智能科普助手` | 副标题 |
| `MAP_TILE_URL` | 否 | 高德路网瓦片 | 地图瓦片地址（含 `{s}{x}{y}{z}` 占位符） |
| `WIKI_API_BASE` | 否 | 维基共享资源 API | 开放图库检索接口 |
| `AI_API_BASE` | 否 | 空 | 可选：在线大模型接口地址 |
| `AI_API_KEY` | 否 | 空 | 可选：大模型密钥（**敏感，切勿入库**） |
| `AI_MODEL` | 否 | `deepseek-chat` | 可选：大模型名称 |

> **设计原则**：`.env` 与生成物 `src/js/env.generated.js` 均已在 `.gitignore` 中排除。**即使完全不配置 `.env`，应用也会回退到内置的公开安全默认值并正常启动** —— 保证仓库克隆后开箱即用。

## 六、AI 协同开发说明（Vibe Coding）

本项目采用 **Vibe Coding（氛围编程）** 模式开发：由参赛选手进行**全局架构设计与 Prompt 意图控制**，AI 辅助生成核心算法与内容语料，选手负责**解耦、Bug 修复与边界条件约束**。完整 Prompt 历史快照见 [`prompts/`](prompts/) 目录。

### 关键人工干预记录

| 模块 | AI 初版缺陷 | 选手干预与修复 |
| --- | --- | --- |
| 图片存储 | 直接转 Base64 导致 LocalStorage 配额溢出、页面卡死 | 引入 Canvas 等比压缩（最长边 800px + JPEG 0.85），单图压至 ~100KB |
| 路线规划 | 未计入景点间车程，时间轴严重偏乐观 | 增加 30 分钟交通缓冲，修复时间戳进位格式，增加 MAX_STOPS 上限 |
| RAG 检索 | 关键词命中率低、空结果无引导 | 加入标点清洗、多路加权排序、空结果兜底话术 |
| 地图标记 | 无图时标记不可见 | 设计「照片优先 / Emoji 降级」双态标记 |
| 知识图谱 | 引入第三方图库导致体积膨胀 | 改为自研 SVG 环形放射布局，约 40 行实现 |
