# 闽韵智小铺

**有据可循，有路可行。** 将福建非遗资料查证、时间约束下的文化探访策划、行程保存与导出连成一个可演示的闭环。

赛道：AI创新应用挑战赛；交付按参赛者确认的 Vibe Coding 规则截图准备。组别以实际报名页面为准。

## 10 分钟复现

### 完整便携参赛包（Windows x64）

1. 将完整参赛文件夹解压到可写目录，保留 `runtime` 与 `01_源代码` 的相对位置。
2. 双击根目录的 **启动作品.cmd**。首次启动不需要安装 Python 或下载依赖。
3. 浏览器打开本机 `http://127.0.0.1:8765`；端口被占用时程序会依次尝试后续 19 个端口，以控制台实际网址为准。
4. 保持启动窗口运行；结束演示时关闭启动窗口，或按 Ctrl+C。

### 单独源码仓库（Windows / macOS / Linux）

需 Python 3.10+；实际验收为 Python 3.13.7 和 Windows Chrome。

```sh
python server.py
# 无需 pip install，无需 npm install，无需模型密钥
```

命令行环境不需自动开浏览器时：`python server.py --no-browser --port 8765`。请通过本地 HTTP 服务打开，直接双击 index.html 不会连接到本地数据库接口。

## 90 秒检查

1. 发现非遗：搜索“簪花”，查看详情和名录正式名称，打开本地摘录。
2. 有据问答：输入“歌仔戏起源在哪里？”，对照来源中“20世纪初兴于台湾”的记载。
3. 输入“泉州南音今天几点演出？”，查看实时信息缺失提示；输入“平潭贝雕的国家级传承人是谁？”，查看无依据拒答。
4. 策划一程：泉州、09:00、4 小时、乘车，生成 3 站方案。切换步行可观察约束变化。
5. 保存，刷新，再到“我的行程”重命名、恢复、导出 HTML / JSON。HTML 可用浏览器打印为 PDF。

## 实际实现

| 部分 | 实现与边界 |
|---|---|
| 资料 | 48 条原作品文化项目；45 条与国家级名录匹配；3 条待核验不参与问答及自动行程 |
| 问答 | 中文双字分词、BM25、实体别名、地区过滤、原文摘录及引用；默认不调用大模型 |
| 可选模型 | 服务端调用兼容 Chat Completions 的 HTTPS 接口；引用编号检查；失败回退原文摘录 |
| 规划 | 最多 8 候选、4 站；穷举可行排列，优先站数、类别多样性，再最小化估算耗时 |
| 保存 | SQLite；服务端重新校验规划参数；支持新增、查询、改名、删除与 JSON 备份导入 |
| 地图 | 本地 Leaflet + 本地 DataV 福建边界，不请求地图瓦片；是文化分布和访问顺序示意 |

坐标沿用原作品的代表区域参考点，未核验为实际营业地点。交通耗时由球面距离×1.35、约定速度和缓冲推算，不含返程，不接入路况、营业时间和预约。输出适用于探访前的文化策划，不是承诺可执行的预约或导航。

## 配置

复制 `.env.example` 为 `.env`（默认无需配置）。密钥仅由 Python 后端读取；浏览器不接收密钥。

| 变量 | 必需 | 默认 / 用途 |
|---|---|---|
| `AI_API_BASE` | 否 | 空；HTTPS 接口根地址，如供应商文档约定的 `/v1` |
| `AI_API_KEY` | 否 | 空；请使用自己的密钥，不提交 Git |
| `AI_MODEL` | 否 | `deepseek-chat`；按供应商实际模型名设置 |
| `MINYUN_DB` | 否 | `var/minyun.sqlite3`；可指定测试专用数据库 |

配置后重启服务，在问答页勾选模型整理。问题和命中的原文片段会发送给所配置的模型供应商。当前交付未配置真实模型密钥，也未声称完成外部模型实测；演示展示本地原文摘录模式。引用编号存在不等于事实一定正确，仍需对照来源。

## 验证

```sh
python tests/test_core.py
python tests/evaluate.py
```

浏览器开发验收另需 `python -m pip install playwright` 和已安装 Chrome，然后执行 `python tests/browser_test.py`。可用 `CHROME_PATH` 指定浏览器路径。Playwright 仅用于开发检查，作品运行不依赖它。

测试数据库由临时目录隔离。测试覆盖资料哈希、别名、拒答、实时边界、时间预算、同城约束、跨日输入、CRUD 与重启持久化、私密文件拒绝、文字转义、导入导出和 5 种视口。30 条检索用例为公开开发回归集，不能解释为真实用户场景的准确率。
