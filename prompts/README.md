# Prompt 历史快照 / Prompt History

本目录记录「闽韵智小铺」在 **Vibe Coding（氛围编程）** 模式下各阶段的关键 Prompt。
它真实反映了项目的开发过程：**选手定义问题与约束 → AI 生成初版 → 选手评审与迭代**。

## 开发范式

```
选手：定义架构边界、拆解任务、编写 Prompt、评审产出、修复缺陷
  ↕
 AI ：生成算法骨架、批量整理结构化语料、提供实现方案备选
```
