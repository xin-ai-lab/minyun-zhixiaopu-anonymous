# 01 · 非遗数据采集与结构化

- **日期**：2026-10-26
- **对应模块**：`src/js/data/sites.js`
- **目标**：把散落的福建非遗信息，整理成可被程序消费的结构化知识库

---

## Prompt 原文

```
你是福建非遗文化领域的资料整理专家。
请帮我整理福建省代表性的非物质文化遗产项目，输出一份结构化数据。

【范围要求】
- 覆盖福建 9 个设区市 + 平潭综合实验区
- 优先收录：联合国人类非遗 > 国家级非遗 > 省级非遗

【字段要求】每条记录必须包含以下 14 个字段，严格按此顺序：
1. 唯一ID（地市首字母 + 两位序号，如泉州用 q01）
2. 项目名称
3. 类别（只能是：戏曲/技艺/民俗/音乐/美食/体育游艺/医药 之一）
4. 所属地市
5. 非遗级别（人类非遗/国家级/省级）
6. 经度、7. 纬度（保留 4 位小数，需真实可定位）
8. 代表性体验地点（具体到街道或场馆）
9. 代表性传承人姓名（不确定就填 "—"，禁止编造）
10. 一句话简介（40-70 字）
11. 历史渊源（100-150 字，含起源朝代与关�键事件）
12. 传承与发扬（100-150 字，含当代真实案例与数据）
13. 游玩攻略（含体验地点/价格/最佳时间/必拍点/顺路美食等，用 <br> 换行）
14. 标签（3-4 个，逗号分隔）

【格式要求】
用 JavaScript 数组元组形式输出，每行一条，便于我直接粘贴使用。

【重要约束】
- 不确定的信息宁缺毋滥，禁止编造传承人姓名与数据
- 经纬度必须来自真实地理位置
```

---

## AI 产出摘要

一次生成了 46 条非遗元组数据，覆盖泉州（9 项）、福州（6 项）、厦门（5 项）、漳州（5 项）、莆田（3 项）、三明（3 项）、南平（4 项）、龙岩（4 项）、宁德（4 项）、平潭（3 项）。

## 选手评审与干预

| 问题 | 处理 |
| --- | --- |
| 初版把「佛跳墙」标注为国家级 | 核实后改为**省级** |
| 部分项目缺失经纬度或坐标明显偏移 | 逐条在地图上校验并修正 |
| AI 对个别项目"补全"了传承人姓名 | **删除存疑项，统一填 "—"**，坚守不编造原则 |
| 类别归属不当（如把南音归入民俗） | 修正为「音乐」 |
| 元组字段顺序偶有错位 | 编写校验逻辑，`RAW.map()` 时逐字段核对 |

## 最终落地

数据以「数组元组」存储以压缩体积，再由 `SITES = RAW.map(...)` 统一映射为语义化对象；
同时抽出 `CATS` 类别字典（名称 / 主色 / 图标）与 `CITIES` 地市顺序表。
